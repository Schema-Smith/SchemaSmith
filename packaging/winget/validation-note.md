A note for validation: these are command-line tools, and running one with no arguments is its normal mode. It starts a real run using the settings file next to it. The settings file that ships in the zip has placeholder connection details, so on a clean machine that run fails to connect and exits non-zero. That is expected, not a broken install. To check that a tool starts, use `--version` or `--help`. All four (`SchemaQuench`, `SchemaTongs`, `DataTongs`, `SchemaShears`) exit 0 with either.

Every executable carries a timestamped Authenticode signature from SchemaSmith LLC, issued through Microsoft's code-signing service. Earlier releases flagged by the installer scan were submitted to Microsoft for analysis: submission `279acea6-e284-4485-a5c8-e6b5769855f4` was closed with "Our scanners show no positive detection, and we have no telemetry indicators for the file(s) submitted either."
